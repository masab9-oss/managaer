# Channel Uploader - Privacy Policy

Last updated: 25 November 2026

Channel Uploader is a small private tool used by its owner to upload and schedule short videos to the owner's own YouTube channels, Islami Waqiat and Hairat Facts. It is not offered to the public and has no other users.

## What data the tool uses

The tool uses the YouTube Data API to upload video files, titles, descriptions and publish times that the owner has created. It requests only the permission needed to upload videos to the owner's own channel, the youtube.upload scope.

## What data is stored

The only data stored is the access credential, an OAuth refresh token, for the owner's own Google account. It is kept as an encrypted secret in the owner's private GitHub repository and is used only to upload the owner's videos. No data about any other person is collected, stored, shared or sold.

## Sharing

No data is shared with any third party. Videos are sent only to YouTube.

## YouTube and Google

This tool uses YouTube API Services. Users are bound by the YouTube Terms of Service: https://www.youtube.com/t/terms

Google Privacy Policy: https://policies.google.com/privacy

## Removing access

Access can be removed at any time from the Google account permissions page: https://myaccount.google.com/permissions
